🛡️ AI Threat Detection Dashboard

Real-time security monitoring dashboard built with Flask, SQLite, JavaScript, HTML, CSS, and Scikit-learn.

🚀 Features
📊 Real-time security event monitoring
🤖 AI anomaly detection
🚨 Threat & risk scoring
🔴 High / Medium / Low severity classification
🔍 Event search and filtering
🔄 Automatic live updates
🩺 Health-check API
🗄️ SQLite database
🌐 Deployed on Render
🛠️ Tech Stack

Python • Flask • SQLite • Scikit-learn • HTML • CSS • JavaScript
